# Results directory

The `*_aligned` files are the current finalized summaries after the monotone route-alignment correction. Older files without `_aligned` are preserved from the first experiment and are superseded; use the aligned comparison, grouped-CV, Bayesian-search, data-quality, and student-test summaries for the final report.

Large candidate feature tables and per-observation student-test predictions are generated locally and excluded from Git. They can be rebuilt by following the commands in the repository README. The evaluator-test partition was not used to generate any development result.
